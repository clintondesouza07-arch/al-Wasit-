Format notes:
- PNG with a transparent background works best (the tile has a white/hover
  background behind it).
- Roughly 300-400px wide is plenty — the site caps display size, so bigger
  files just mean slower page loads for no visual benefit.
- Until a file lands here, the site automatically falls back to the
  existing styled text wordmark for that brand — nothing breaks either way.

Where to get these (they're trademarked assets, not something to grab from
a random search result):
- Each manufacturer's official "media kit" / "brand assets" / "press" page
  usually has an approved logo download (e.g. a "Newsroom" or "Press" link
  in their site footer).
- If Al Wasit is an authorized/registered dealer for a brand, that brand's
  dealer portal is often the cleanest source and may specify usage rules
  (clear space, no recoloring, no distortion).
- AWM doesn't need a file here — the homepage already uses the real Al
  Wasit mark (icon-512.png) for that tile since AWM is your own brand.
